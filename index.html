What ends up in the CSV

  • Coordinates are decimal degrees, WGS84, written exactly as stored in the KML. Altitude is in metres when the file has it.
  • folder is the path of Documents and Folders above each placemark, joined with " / ", so you can filter by survey or site.
  • Attribute fields come from ExtendedData (Data and SchemaData) and, if the option is on, from two-column tables inside descriptions, which is how ArcGIS and many other tools export attributes.
  • length_m and area_m2 are geodesic estimates for lines, tracks and polygon outlines. Holes in polygons are not subtracted.
  • The map offers satellite, ocean and street basemaps from Esri and OpenStreetMap. Loading tiles tells those services which area you are viewing, but your file contents never leave the browser. Without internet the page falls back to a plain plot.
  • Network links, image overlays and 3D models have no rows. KMZ files with several KML files inside are all read.
